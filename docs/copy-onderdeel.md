## Handmatig

- `onboarding/werkzaamheden/startpakket-form.tsx`: "werkzaamheid/werkzaamheden" → "onderdeel/onderdelen"
- Schakelaar op onderdeel-kaart (mobiele lijst), sheet en desktop-paneel: "Op je website" / "Zichtbaar voor klanten" → **"Zichtbaar"**; aria-label → "Zichtbaar voor klanten: <naam>"
- Verborgen onderdeel: gedimde kaart + label **"Verborgen voor klanten"** (was "verborgen" in het desktop-lijstje)
- Onderbalk mobiel: wereldbol-knop verwijderd; "Op website zetten" (gast: "Account maken") staat in het ⋯-menu, de balk bevat alleen "+ Onderdeel" (het label paste niet op 360 px)
- Checklist "Op je website gezet" → "Staat op je website" (editor, rekentools-overzicht, Vandaag)
- "Op je website plaatsen" → "Plaatsen op je website" (`editor/paneel-instellingen.tsx`)
- Landing prijstabel: rij "Op je website" → "Rekentool op je website" (`lib/landing/feiten.ts`)
- Regel in AGENTS.md vervangen door: "In de UI heet het "onderdeel"; het woord "werkzaamheid" komt niet meer voor." (bewaakt door `app/lib/copy-regels.test.ts`)
